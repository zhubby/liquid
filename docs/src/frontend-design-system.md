# Frontend Design System

The `liquid-ui` design system lives with the frontend package:

- [Master Liquid Glass design system](../../liquid-ui/design-system/MASTER.md)
- [Dashboard page overrides](../../liquid-ui/design-system/pages/dashboard.md)

Use the master document for global visual, layout, motion, accessibility, and
component rules. Use page override files when a specific page needs stricter
composition rules than the global system.
